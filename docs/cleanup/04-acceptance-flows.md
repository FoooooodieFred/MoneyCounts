# 核心验收流程（阶段2盘点）

> 后续每一轮整理（阶段3+）结束后，至少跑通下列流程，确认无功能回退。  
> 数据均在 LocalStorage；建议验收前导出一份 JSON 备份。

## AF-1 自然语言记账（最高频）

1. 打开 `/`，在快速输入区输入至少两句中文支出（可含「昨天」等相对日期）。  
2. 提交后出现可编辑预览；改一条金额/备注。  
3. 确认写入后，今日明细或对应日期明细可见新记录。  
4. **通过标准**：预览可编辑；确认后数据持久（刷新仍在）。

## AF-2 手动明细表格

1. 从首页打开「手动记账 / 完整表格」弹窗（`data-action="open-manual-ledger"`）。  
2. 在某一类目填写金额与备注；用键盘 Tab/方向键移动；新增一行。  
3. 关闭弹窗后首页今日明细同步；刷新页面数据仍在。  
4. **通过标准**：表格增改可见；焦点契约不崩；数据写入 LocalStorage。

## AF-3 统计与多货币

1. 在有多笔不同币种记录的前提下，查看当日/本周/本月汇总。  
2. 切换「分币种 / 合并」口径；切换统计货币。  
3. 展开饼图与全年趋势（懒加载图表出现）。  
4. **通过标准**：数字口径切换合理；图表能渲染；无白屏。

## AF-4 旅游模式闭环

1. 进入 `/travel`，开启或配置行程（同行人、货币等）。  
2. 录入至少一笔旅游支出；查看分账/汇总。  
3. 结束旅游并写入历史；打开历史详情；可选删除后撤销（若 UI 提供）。  
4. **通过标准**：行程状态正确；历史可查；返回首页账本未异常清空。

## AF-5 备份导出/导入

1. 打开 `/settings`，导出 JSON 完整备份。  
2. 故意改动一笔账本数据后，再导入刚导出的文件。  
3. 确认出现导入预览；确认覆盖后数据回到备份状态。  
4. **通过标准**：必须有预览确认；覆盖后关键字段（账本/设置/旅游）恢复合理。

---

## 验收使用约定

- 每轮只改一小步后跑 AF-1～AF-5（或至少 AF-1、AF-2、AF-5）。  
- 任一失败：**回退到最近 git 基线/tag**，不继续堆改动。  
- 本文件本身不修改产品行为。
